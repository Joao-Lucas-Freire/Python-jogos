#  Python — Desenvolvimento de Jogos

Repositório dedicado aos meus estudos de desenvolvimento de jogos utilizando **Python**. O objetivo é praticar lógica de programação, explorar bibliotecas voltadas à criação de jogos e desenvolver pequenos projetos durante minha jornada de aprendizado.

## Objetivos

- Aprender os fundamentos do desenvolvimento de jogos.
- Praticar lógica de programação com Python.
- Desenvolver jogos 2D e experimentar novas mecânicas.

##  Tecnologias

- **Python** — linguagem de programação.
- **Pygame** — biblioteca para desenvolvimento de jogos 2D.
- **Git e GitHub** — versionamento e organização dos projetos.

##  Aprendizado

Este repositório acompanha minha evolução nos estudos de desenvolvimento de jogos. Os exercícios e projetos serão adicionados gradualmente conforme avanço no conteúdo e coloco em prática os conhecimentos adquiridos.

Além de acompanhar as aulas, pretendo experimentar modificações e desenvolver ideias próprias para consolidar meu aprendizado.
